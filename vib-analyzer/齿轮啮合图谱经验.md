## 1. 一页纸判读流程

1. **先算表，再看谱**：每个案例第一页都是齿轮参数表——各级齿数、传动比、自转/公转转频、各级啮合频率（GMF）。判读的所有结论都建立在这张表上，谱图只是验证。
2. **在谱上找 GMF**：先找该级的啮合频率及其 2×、3×（案例里常出现在 1.5–2.5 kHz 处的“峰族”）。找不到 GMF 就看错级了。
3. **量边带间隔 Δf**：GMF 两侧的边带间距是最值钱的信息，它直接指出“哪根轴上的齿轮在恶化”（见 §3）。
4. **算 Δf 与 GMF 的比值**：若 Δf = GMF/n（n 为这对齿轮齿数的公约数），说明沿周向均布的 n 个齿都有损伤（见 §4）。
5. **回到时域量冲击周期**：冲击间隔 = 1/Δf；数一数“每转几次冲击”，就是损伤齿数（见 §5）。
6. **看趋势定严重度**：单根窄边带 → 边频簇 → 谐波族 → 断齿，是一条可复现的恶化链（见 §6）。

## 2. 频率词典

| 名称 | 怎么算 | 在谱上长什么样 |
|---|---|---|
| 高速级啮合 GMF | 高速级齿数 × 高速轴转频 | 高频段一根主峰 + 2×/3× 谐波族（案例 526.1/555.5/482.9/551.7/476 Hz） |
| 中间级啮合 GMF | 中间级齿数 × 中速轴转频 | 150–200 Hz（案例 155.6/148.9/194.6/197.5 Hz） |
| 行星级啮合 GMF | 内齿圈齿数 × 行星架转频 | 30–60 Hz，低频段最显眼的一根（案例 51.71/51.73/35.82/34.6 Hz） |
| 轴转频 | rpm/60 | 边带的间隔；时域冲击的周期 |
| 行星轮通过/啮合均分 | GMF ÷ 行星轮个数 | 行星级谱线上 1/3 GMF 的等间隔峰（案例 35.8/3 = 11.9 Hz） |
| 齿数公约数 n | gcd(齿数₁, 齿数₂) | 边带间隔 = GMF/n（案例 n=3 → 175.3 Hz；n=11 → 50.5 Hz） |

> 材料里反复出现“注：各级齿轮齿数公约数均为 3”“高速级一对齿轮齿数公约数为 11”——**公约数是判读参数，不是变速箱参数**，做参数表时要一并记下来。

## 3. 边带间隔 → 故障定位（核心规则）

| 边带间隔 Δf | 说明 | 材料证据 |
|---|---|---|
| = 高速轴转频 | 高速级小齿轮/大齿轮 | 1.1 边频簇间隔 = 高速轴转频 |
| = 中速轴转频 | 中间级齿轮（大/小齿轮） | 2.1（7.159 Hz）、2.2（6.998 Hz）、3.1（7.178 Hz） |
| = 低速轴转频 | 低速级齿轮 | 4.1（2.017 Hz，低速轴轴向测点） |
| = 3 × 太阳轮自转频率 | 行星级太阳轮 | 5.1（7.388 Hz = 3×2.46）、5.2（7.47 Hz） |
| = GMF ÷ 行星轮个数 | 行星级行星轮 | 6.1（11.9 Hz = 35.8/3） |
| = GMF ÷ 公约数 n | 均布的 n 个齿损伤 | 1.3（1/3 GMF = 175.3 Hz）、1.4（1/11 GMF = 2×高速轴转频 = 50.5 Hz） |

**为什么是“3 倍太阳轮自转”而不是 1 倍**：3 个行星轮沿周向均布，每个行星轮经过同一个太阳轮缺陷时打一次，所以太阳轮转一圈出现 3 次冲击。这是行星级最容易被漏掉的一条。

## 4. 边带形态 → 严重程度

| 形态 | 含义 | 材料证据 |
|---|---|---|
| 单根、窄、幅值远小于 GMF | 早期：微动磨损、轻微点蚀 | 1.1 高速级一对齿轮齿面微动磨损 |
| 边带成簇（多根、间隔固定） | 发展中：齿面剥落/磨损 | 1.1“边频簇”、1.3 高速轴齿轮磨损 |
| 主峰变成“边带族”+ 谐波抬高 | 严重：局部崩齿、断齿前兆 | 1.4 磨损加剧 + 局部崩齿（新齿轮第 5 个月） |
| 时域出现周期性冲击、峰值/尖峰系数升高 | 已进入冲击性故障 | 1.2 首次剥落 → 6 个月后断齿 |

材料的 1.2 案例是完整恶化链：**第一次检查发现齿面剥落 → 6 个月后发展为断齿**，中间只做趋势复测。这条对“要不要停机”最有参考价值。

## 5. 时域波形规则

- 用两个光标卡住相邻冲击，得到间隔 Δt → f = 1/Δt；再除以轴转频，得到“每转冲击次数”＝损伤齿数。
- 案例读数：中速轴 7.159/6.998/7.178 Hz、低速轴 2.017 Hz、太阳轮 3× 自转 7.388/7.47 Hz。
- 冲击幅值不稳、尖峰系数（Crest Factor）>5 时，优先怀疑断齿或异物（6.3 异物进入导致行星轮局部崩齿）。
- 波形上要标“间隔是哪个轴的转频”——材料每页波形都写这句，是判读的锚点。

## 7. 行星级的三条专有规则

1. **内齿圈固定、3 个行星轮公转+自转**（7.2 有啮合模型图）。所有行星级故障都表现为“低频段 GMF 及其边带”，不要在高频段找。
2. **太阳轮**：冲击间隔 = 3 × 太阳轮自转频率（因为 3 个行星轮均布）；谱上是 3× 边带族。
3. **行星轮**：谱线间隔 = GMF ÷ 行星轮个数（案例 35.8/3 = 11.9 Hz）；行星轮是箱内**唯一双侧齿面参与啮合**的齿轮（6.2 注释），所以磨损/剥落发展快。
4. 早期风电行业行星级多用直齿（6.3 注释）；直齿的调制更“硬”，边带更清晰，但也更容易被误当成轴承故障。
5. **两级行星**要分清是哪一级：7.2 在“一级行星大齿圈”测点上，被标注的是 **111.8 Hz 二级行星啮合频率**——齿轮箱壳体上多个行星级共用测点，先确认频率属于哪一级再下结论（该案例注释“一、二级行星轮个数均为 3”）。

## 8. 容易踩的坑

- **只看 1× 和总振值**：18 个案例里没有一个是靠总振值发现的，全部靠“GMF + 边带”。
- **把 GMF 谐波当成另一级啮合**：同一根轴的 GMF 有 2×/3×，先按齿数算一遍再下结论。
- **忽略公约数**：n=3 和 n=11 的边带间隔完全不同，若不知道公约数会把“3 个齿均布损伤”误判成“某轴转频调制”。
- **在错误的测点上找**：材料按测点分工——高速轴 Horizontal/Vertical、中速轴 Horizontal/Axial、低速轴 Axial、行星级 Vertical/Horizontal、大齿圈 Horizontal。
- **只看加速度**：内齿圈/低速级用**速度谱**更容易看到 GMF 主峰（7.1 就是速度谱）。
- **单次结论**：1.2 的教训是同一测点隔月复测才能判定“剥落 → 断齿”的进程。

## 9. 落到本程序上可以做什么

### 已实现（2026-11）

- **边带自动识别**：`sideband_spacing` / `gear_sideband_verdict` —— 在 GMF 两侧窗口找峰、取间隔中位数，再和各轴转频、GMF÷gcd、GMF÷行星轮数、N×太阳轮自转比对（容差 6%，允许多倍关系）。结论渲染成谱图右上角的「**齿轮判读**」卡：`间隔 → 命中谁 → 指向什么 → 边带/主峰 严重度`。
- **GMF÷齿数公约数 族**：`数据\机型库.json` 的 `gears` 新增 `gcd`，谱图上用紫色画 `GMF/n` 族（材料 1.3/1.4 那种等间隔峰）。
- **行星级专用标注**：`planets` 字段（五峰 = 3）→ 画「N×太阳轮自转」与「GMF÷行星轮数」，绿色。
- 齿轮对话框新增「边带依据」：轴转频 / GMF÷公约数 / 两者都画。
- 数据侧：`tools\build_libs.py` 会从现场表里自动算 `gcd`（同啮合频率那对齿轮）与 `planets`（附件2「齿轮数」列）。
- **写进报告**：
  - `report_gear_scan` 在报告故障扫描时跑一遍（每测点取 RMS 最大的记录），结论进 `agg[...]["gear"] / ["gear_lab"]`；
  - 齿轮结论能把测点单独抬成「关注 / 警告」（边带/主峰 ≥0.12 / ≥0.30），不依赖轴承报警；
  - 有模板时：`tpl_fill._fill_conclusions` 把结论写进机组结论段（有轴承报警则追加“同时该测点齿轮啮合异常…”，只有齿轮则单独成句）；
  - 无模板时：`build_template_report` 在「报告概述」和「三、超限测点清单」各写一段齿轮边带判读，并给处理建议；
  - 报告插图的上幅值谱会画各级 **GMF 标线**。

### 还可以做

1. **趋势化**：同一测点逐月记录「边带/主峰比、边带根数」，复现 1.2 那种“剥落 → 6 个月断齿”的进程判断。
2. **行星级参数细化**：材料参数表把“自转/公转”分开给，现在 `shafts` 只有转频比；要完全复刻行星级判读，需要把行星架公转、行星轮自转、太阳轮自转拆成三个字段。
3. **多级行星**：7.2 说明箱体上多级行星共用测点，判读前要按 GMF 值先确认是哪一级（程序现在按「谱上最明显的一级」自动挑）。
