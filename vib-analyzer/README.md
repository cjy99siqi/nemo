# 振动分析程序（明阳 2.0MW 机组）

风电振动数据分析工具，支持 CSV 批量读取、时域/频域/包络谱分析、轴承故障阶次匹配、测点标注与月度报告生成。

## 文件说明

| 路径 | 说明 |
|---|---|
| `振动分析.py` | 主程序（唯一入口，约 6400 行） |
| `启动振动分析.bat` | 双击启动（自动找同目录的 .py 用 pythonw 运行） |
| `requirements.txt` | 依赖清单 |
| `数据\` | 轴承参数库（明阳 2.0MW.xlsx、运达各类型机组振动档案库.xls 等） |
| `输出\` | 建议把导出的图谱/报告放这里 |

程序运行后会在同目录自动生成：`gui_state.json`（界面状态）、`vib_cache.db`（测点缓存）、`vib_annotations.json`（标注）、`trend_summary.json`、`vib_speeds.json`。

## 换电脑使用

1. 安装 Python 3.11～3.13（安装时勾选 Add Python to PATH）
2. 打开命令行执行：
   ```
   pip install -r requirements.txt
   ```
3. 双击 `启动振动分析.bat`

> 如果提示缺少 tkinter：重装 Python 时勾选 "tcl/tk and IDLE"。
> 如果 `xlrd` 读取 .xls 报错：`pip install "xlrd>=2.0"`。

## 主要功能

- 读取采集器 CSV（文件名格式 `<项目>_<机组>_<测点>_<fs>Hz_<时长>s_加速度值_[rpm_]<时间戳>.csv`）
- 时域、幅值谱、包络谱、趋势、瀑布图
- 轴承故障阶次匹配（BPFO/BPFI/BSF/FTF，可在界面里自定义倍数）
- 齿轮啮合频率与边频带标记
- 机组/测点树 + 机组编号快速跳转
- 月度报告生成（配合田家寨报告模板）

## 数据目录约定

默认项目为「京能田家寨」（原「府谷」），测点 9 个：
主轴承前/后轴径向、齿轮箱一级齿圈径向、齿轮箱中部径向、齿轮箱高速轴后轴承径向/轴向、发电机驱动端轴向/径向、发电机非驱动端径向。

机组代码 `101#～125#` 对应报告里的 `1#～25#`。
